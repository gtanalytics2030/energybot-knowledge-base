TITLE: Annexure-4: Required Details for Wind-Solar Hybrid Project Provisional Registration
SUMMARY:
This form captures all details required for provisional registration of wind-solar hybrid power projects (with or without BESS). It collects applicant profile, company details, grid connectivity preferences, wind turbine specifications, solar PV specifications, hybrid project configuration (Type-A existing hybridization or Type-B new hybrid), BESS details (if applicable), and processing fees. Hybrid projects enable co-location of wind and solar resources to optimize land use and provide better grid stability.

SECTION K: HYBRID PROJECT ADVANTAGES (For Context)

Hybrid projects are encouraged because they:
- Optimize land use (combine wind and solar on same site)
- Improve grid stability (complementary generation profiles)
- Reduce transmission infrastructure costs (single connection point)
- Better capacity factor (wind at night/cloudy days, solar at daytime)
- Enable better energy storage integration with BESS

SECTION L: TYPE-A vs TYPE-B DECISION MATRIX

| Aspect | Type-A (Existing Hybridization) | Type-B (New Hybrid) |
|---|---|---|
| Basis | Existing wind/solar project + new resource | Design both from scratch |
| Approval | Existing project must be registered | Fresh registration for hybrid |
| Timeline | Faster (modifying existing) | Longer (completely new design) |
| Land | Existing land use + marginal addition | Requires total land planning |
| Grid | Existing connectivity upgrade | New grid study required |
| Commissioning | Phased (existing then new) | Single commissioning |

PROCESSING TIMELINE:

- Application submission with complete documents: Day 1
- Preliminary verification: 2-3 days
- GETCO coordination (grid impact): 2-3 days
- Total approval: 3-5 working days
- Validity: Until development permission (24 months)

IMPORTANT NOTES FOR HYBRID PROJECTS:

✓ Type-A: Adding new resource to existing GIREP-2025 registered project
✓ Type-B: Both wind and solar designed as single integrated hybrid
✓ Single grid connection point (reduces transmission costs)
✓ Single PPA/wheeling agreement (with both resources)
✓ Total capacity = MAX(wind, solar) for grid planning
✓ BESS recommended for hybrid (improves grid stability)
✓ Land area: Minimum 2-2.5 hectares per MW of larger component
✓ Both components must meet equipment certification (ALMM/RLMM)
✓ Processing fee same as wind/solar (Rs. 11,800)

KEY ADVANTAGES OF HYBRID OVER SEPARATE PROJECTS:

1. Land Optimization: 2-2.5 hectares serves 10 MW wind + 10 MW solar (hybrid) vs. 50+ hectares for separate
2. Grid Connection: Single connection point (reduce GETCO approval complexity)
3. PPA Simplification: One agreement covers both resources
4. Cost Efficiency: Shared infrastructure (buildings, roads, security)
5. Grid Stability: Complementary generation (wind + solar) reduces variability
6. BESS Integration: Battery works with both resources for optimal charging/discharging

CRITICAL REQUIREMENTS:

⚠️ Type-A: Existing project must be properly registered and in development stage (not yet commissioned)
⚠️ Type-B: Clear definition of physical layout and resource configuration required
⚠️ Grid: Single substation connection (or coordinated multi-substation design)
⚠️ Land: Physical proximity of wind and solar sites essential for hybrid operation
⚠️ Coordination: Both resources must be designed with mutual electrical/mechanical considerations
