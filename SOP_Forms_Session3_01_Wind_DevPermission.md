TITLE: Annexure-6: Comprehensive Requirements for Wind Power Development Permission Application (Detailed Technical Design)
SUMMARY:
This form is for detailed development permission of wind power projects (with or without BESS). Unlike provisional registration, development permission requires comprehensive technical design, site assessment, environmental clearance, and detailed specifications. Form captures micro-siting details, WTG final specifications, foundation design, electrical system design, grid protection, environmental impact, O&M plan, and processing fees. Development permission must be obtained before starting civil works.
KEY TOPICS: Wind Development Permission, Detailed Design, WTG Specifications, Micro-siting, Foundation Design, Grid Protection, Environmental Assessment, GEDA
TEXT:
ANNEXURE-6: WIND POWER PROJECT - DEVELOPMENT PERMISSION APPLICATION
COMPREHENSIVE TECHNICAL DESIGN CHECKLIST

SECTION A: APPLICANT & PROJECT REFERENCE

1. Applicant Company Details
   - Name, address, contact information
   - PAN, GST registration
   - Type of applicant (developer, park developer, etc.)
   - Entity registration documents (certified copies)

2. Project Registration Reference
   - Provisional Registration Certificate Number (from Annexure-1)
   - Date of Provisional Registration
   - Current project status
   - Any modifications from provisional registration

3. Authorized Signatory
   - Name, designation, contact details
   - Certified Board Resolution authorizing signatory

SECTION B: DETAILED PROJECT SITE ASSESSMENT

1. Micro-Siting Analysis
   - Exact WTG locations (latitude/longitude for each turbine)
   - UTM coordinates for all 4 corners of site
   - Elevation data (AMSL for each WTG location)
   - Site accessibility and terrain analysis
   - Obstacles, nearby structures (trees, buildings, power lines)

2. Wind Resource Assessment (Detailed)
   - Wind speed at hub height (measured or extrapolated data)
   - Wind shear coefficient (alpha value)
   - Annual wind speed variability
   - Seasonal wind patterns
   - Wind direction distribution
   - Weibull parameters (k, c)
   - Expected capacity factor (%)
   - Wind resource map/report

3. Site Survey & Mapping
   - Detailed site survey maps (1:5000 or better)
   - Contour maps showing elevation changes
   - Obstacle identification and distances
   - Nearby infrastructure (roads, transmission lines, buildings)
   - Land use classification
   - GPS survey points

SECTION C: WIND TURBINE GENERATOR - FINAL SPECIFICATIONS

1. WTG Specifications (Final Design)
   - Make, model, and exact configuration
   - Rotor diameter (meters)
   - Hub height (meters) - FINAL HEIGHT
   - Rated capacity (MW)
   - Cut-in wind speed (m/s)
   - Rated wind speed (m/s)
   - Cut-out wind speed (m/s)
   - Survival wind speed (m/s)
   - Air density assumption (kg/m³)

2. Equipment Certifications
   - ALMM (Approved List of Makes and Models) approval certificate
   - Certificate number and validity date
   - IEC 61400-1 compliance certification
   - Any other applicable certifications

3. Power Curve & Performance
   - Manufacturer power curve (verified against actual model)
   - Expected annual energy output (kWh) - CONSERVATIVE ESTIMATE
   - Capacity factor at site (%) - CONSERVATIVE
   - Performance warranty terms
   - Performance guarantee percentage

SECTION D: FOUNDATION & CIVIL DESIGN

1. Foundation Design (Detailed Geotechnical)
   - Soil investigation report (boring logs, SPT values)
   - Bearing capacity analysis
   - Foundation type (pile/pad/anchor design)
   - Foundation depth (meters)
   - Concrete grade and reinforcement design
   - Design wind speed used (km/h)
   - Seismic zone classification (if applicable)
   - Licensed structural engineer's calculations & stamp

2. Electrical Connections
   - Generator specifications and voltage
   - Internal cabling from generator to inverter/transformer
   - Cable sizing and protection

3. Tower Structure
   - Tower type (lattice/monopole)
   - Tower material and gauge
   - Fatigue life (years) at expected cycles/year
   - Lateral deflection limits
   - Foundation-to-tower connection details

4. Safety Systems
   - Overspeed protection (pitch/stall/brake)
   - Emergency shutdown mechanism
   - Lightning protection and grounding
   - Safety gates and warning signs
   - Climbing equipment if applicable

SECTION E: ELECTRICAL SYSTEM DESIGN (DETAILED)

1. Inverter/Power Conversion
   - Make, model, and rating (kW)
   - DC voltage input range
   - AC output voltage (400V, 3-phase, 50Hz)
   - Efficiency curve
   - Warranty terms

2. Transformer (if applicable for >100 kW)
   - Primary voltage and secondary voltage
   - Rating (kVA)
   - Cooling type
   - Impedance and losses
   - Manufacturer specifications

3. Grid Connection Electrical Design
   - AC distribution from inverter/transformer to grid connection point
   - Cable sizing (cross-section, insulation)
   - Conduit/routing plan
   - Breakers, isolators, protective devices
   - Earthing system design (resistance target <5Ω)

4. Protection & Control System
   - AC protection: MCBs, isolators, SPDs
   - DC protection: Fuses, isolators
   - Over/under voltage protection (thresholds)
   - Over/under frequency protection (thresholds)
   - Anti-islanding detection
   - Automatic disconnection settings

5. Metering System
   - Revenue meter type and accuracy class
   - Meter location and installation method
   - Remote monitoring connection (if applicable)

SECTION F: GRID CONNECTIVITY TECHNICAL REQUIREMENTS

1. GETCO/DISCOM Approval
   - Technical Feasibility Report (TFR) from GETCO/DISCOM
   - Grid connection approval/NOC
   - Connection point specifications
   - Grid strengthening requirements (if any)
   - Coordination committee meetings minutes (if required)

2. Grid Impact Assessment
   - Voltage profile impact analysis
   - Fault level contribution analysis
   - Stability analysis
   - Harmonic distortion assessment

3. Grid Protection Coordination
   - Protection relay settings (coordination with grid)
   - Fault clearance time
   - Automatic trip-out settings

SECTION G: GEOTECHNICAL & ENVIRONMENTAL

1. Geotechnical Survey Report
   - Boring locations and depths
   - Soil stratification and classification
   - Groundwater table depth
   - SPT N-values
   - Bearing capacity calculation
   - Foundation recommendations

2. Environmental Assessment
   - Environmental Impact Assessment (EIA) if required
   - Wildlife impact (especially bird/bat migration)
   - Noise impact assessment (target <50 dB at distance)
   - Shadow flicker analysis (if near habitation)
   - Visual impact assessment
   - Environmental mitigation measures

3. Land & Legal Status
   - Finalized land documents (purchase deed/long-term lease)
   - Land measurement/survey
   - Lease period confirmation (if leased)
   - Lessor consent (if leased)
   - Non-agricultural (NA) permission or equivalent
   - No encumbrance certificate

3. Compliance Documents

SECTION I: BATTERY ENERGY STORAGE (IF APPLICABLE)

BESS Integration (if project includes storage):

   - Battery chemistry and specifications
   - BMS details

2. Hybrid Operation Strategy

SECTION J: O&M PLAN & COMMUNITY ENGAGEMENT

1. Operation & Maintenance Plan

   - Preventive maintenance program
   - Troubleshooting procedures

2. Community Engagement

   - Local employment plan
   - Community benefit-sharing mechanism
   - Grievance redressal procedure
   - Environmental management plan

SECTION K: TIMELINE & COMMISSIONING PLAN

1. Detailed Project Schedule
   - Milestone dates for:
     * Land preparation
     * Foundation work
     * Tower erection
     * WTG installation
     * Electrical work
     * Testing and commissioning
   - Total project duration

2. Commissioning Plan

   - Grid synchronization procedure

   - Commercial operation date

SECTION L: PROCESSING FEES & CHARGES

Development Permission Fee Structure:

1. Fee Calculation
   - < 1 MW: Rs. 10,000
   - 1-10 MW: Rs. 15,000 per MW
   - > 10 MW: Rs. 20,000 per MW
   - + 18% GST

   Examples:
   - 5 MW: 5 × 15,000 = Rs. 75,000 + GST = Rs. 88,500
   - 15 MW: 15 × 20,000 = Rs. 3,00,000 + GST = Rs. 3,54,000

2. Payment Terms
   - Online through RE Portal
   - Non-refundable
   - Receipt required for application

IMPORTANT REQUIREMENTS FOR DEVELOPMENT PERMISSION:

✓ ALL documents must be professionally prepared (not hand-drawn)
✓ All calculations must be sealed by licensed engineers
✓ Wind data must be site-specific or professionally extrapolated
✓ Geotechnical survey is NON-NEGOTIABLE
✓ GETCO approval is MANDATORY before approval
✓ Environmental assessment required if applicable
✓ ALMM certificates required for all equipment
✓ 24-month validity from issue date
✓ Commissioning must occur before expiry

TIMELINE FOR DEVELOPMENT PERMISSION:

- Complete application submission: Day 1
- Document verification: 5-7 days
- GETCO grid impact review: 10-15 days
- Technical scrutiny: 5-10 days
- Environmental review: 5-10 days (if required)
- TOTAL APPROVAL: 30-45 working days

KEY DIFFERENCES FROM PROVISIONAL REGISTRATION:

Provisional Registration:
- Basic information only
- Quick approval (3-5 days)
- Rs. 11,800 fee
- Next step: Development Permission

Development Permission:
- Detailed technical design required
- 30-45 day approval process
- Rs. 15,000-20,000/MW fee
- Can start civil works after approval
- 24-month validity for project execution
